⚙️ Configuration

Pour que les leads s'enregistrent automatiquement, vous devez déployer un Google Apps Script et coller son URL ici.

Étape 1 — Créer le Google Apps Script

Allez sur script.google.com, créez un nouveau projet, et collez le code du fichier google-apps-script.gs fourni dans ce repo.

Étape 2 — Déployer comme application Web

Cliquez Déployer → Nouvelle déployé, choisissez Application Web, accès Tout le monde. Copiez l'URL générée.

Étape 3 — Coller l'URL ci-dessous

L'URL ressemble à : https://script.google.com/macros/s/AKfy.../exec
