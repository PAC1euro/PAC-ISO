⚙️ Configuration Google Apps Script

Étape 1 — Créer un Google Sheet

Allez sur sheets.google.com et créez un nouveau classeur. Notez son ID dans l'URL.

Étape 2 — Ouvrir Apps Script

Dans le Sheet : Extensions → Apps Script. Collez le contenu du fichier google-apps-script.gs fourni dans ce repo.

Étape 3 — Déployer

Cliquez Déployer → Nouveau déploiement. Type : Application Web. Exécuter en tant que : Moi. Accès : Tout le monde. Copiez l'URL.

Étape 4 — Coller l'URL + mettre à jour client.html & index.html

Collez l'URL ici ET remplacez VOTRE_URL_GOOGLE_APPS_SCRIPT dans client.html et index.html par cette URL.
