⚙️ Configuration Firebase

Créez un projet Firebase gratuit en 3 étapes — aucune carte bancaire requise.

Étape 1 — Créer un projet

Allez sur console.firebase.google.com → "Ajouter un projet" → donnez un nom → désactivez Analytics → Créer.

Étape 2 — Activer la base de données

Dans le menu gauche : Build → Realtime Database → Create Database → choisissez un emplacement → Start in test mode → Enable.

Étape 3 — Copier l'URL

L'URL apparaît en haut de la page, format : https://MON-PROJET-default-rtdb.firebaseio.com
Collez-la ici :

Cette URL doit aussi être ajoutée dans client.html et index.html (variable FIREBASE_URL) pour que les leads s'enregistrent automatiquement.
